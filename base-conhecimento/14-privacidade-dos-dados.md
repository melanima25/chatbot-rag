# Privacidade dos dados

O chatbot pede apenas nome e telefone, e somente quando o cliente quer falar com um atendente. Não pedimos documentos, endereço ou dados de cartão pelo chat.

Por ser um projeto de demonstração, orientamos usar dados fictícios. As conversas são armazenadas para fins de teste e podem ser apagadas a qualquer momento.
